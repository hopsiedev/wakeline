# Third-party licenses

## Minimal UI Kit (free edition)

The desktop interface in `apps/desktop` is based on
[minimal-ui-kit/material-kit-react](https://github.com/minimal-ui-kit/material-kit-react),
released under the MIT License. Its full license text is in
[`apps/desktop/LICENSE-minimal-ui.md`](apps/desktop/LICENSE-minimal-ui.md).

Only the free MIT edition is used. No code from the paid Minimal UI editions is
included in this repository.

## Dependencies

Rust crates and npm packages keep their own licenses, listed in `Cargo.lock` and
`apps/desktop/package-lock.json`.
